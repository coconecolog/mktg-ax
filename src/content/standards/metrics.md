# 数字の定義（KPI・予算）

MKTG.AXの記事・資料・ツールは、すべてこのページの式と基準で計算しています。知りたい指標の見出しから読んでください。記事・ツールの指標名のリンクからは、その見出しに直接移動します。

最終更新日：2026-10-20（[更新履歴](#history)）

計算例の数字は、[基本モデル](/standards/model)の架空の会社のものです。業界の平均や目安ではありません。

## 共通のルール {#rules}

単位、使う用語、費用への人件費の入れ方を決めています。どの指標も、このルールの上で計算します。

- 単位：万円。時間単価だけは円で書きます
- 使う用語：受注、マーケ経由、平均単価
- 費用：外部に払う費用と人件費の合計です
- 端数：計算は丸める前の値で行い、結果だけを丸めて示します

### 人件費を入れる {#labor-cost}

費用には、外部に払う費用に加えて人件費を入れます。内訳がわかるときは、外部費用・人件費・合計の3行で示します。

経営は、人件費も含めて投資を見ています。外部費用だけで計算すると、社内の時間を多く使う施策（記事制作、MAツールの運用、ウェビナーなど）が実際より安く見えるというわけです。

人件費がまだわからないときは、0として計算できます。その場合は、人件費を入れていない数字だと結果に書き添えます。

### 施策ごとの人件費の配り方 {#labor-allocation}

施策ごとの人件費は、その施策にかける時間の割合で、マーケの人件費（年額）を配って出します。

```
施策の人件費＝その施策にかける時間の割合×マーケの人件費（年額）
時間の割合＝その施策の時間÷すべての施策の時間の合計
```

- 共通の作業（集計・報告、営業との連携、予算づくり）の時間は、施策の時間の比で配ります
- マーケの人件費には、施策に協力する営業の時間も含めます

計算例（架空の会社の例・成長期）：370×展示会の時間120÷施策の時間の合計742＝人件費60

## 目標の逆算 {#backcast}

全社の売上目標から既存顧客の売上とマーケ以外の見込みを引いてマーケ経由の売上目標を出し、受注件数・商談数・リード数を順に割り戻します。

```
新規の売上目標＝全社の売上目標−既存顧客の売上
マーケ経由の売上目標＝新規の売上目標−マーケ以外（紹介・営業の開拓）の見込み
受注件数＝マーケ経由の売上目標÷平均単価
商談数＝受注件数÷受注率
リード数＝商談数÷商談化率
```

率の取り方：

- 率は今期の実績を使います
- 受注率は、決着した商談（受注＋失注）だけで出します。進行中の商談を分母に入れると、受注率が実際より低く出てしまいます

計算例（架空の会社の例・成長期）：

```
新規の売上目標14,500＝全社の売上目標152,500−既存顧客の売上138,000
マーケ経由の売上目標3,000＝新規の売上目標14,500−紹介・営業の開拓の見込み11,500（46件×250）
受注件数12＝3,000÷平均単価250
商談数42＝12÷受注率（12÷42）
リード数285＝42÷商談化率（42÷285）
```

## 判定の指標 {#indicators}

費用（人件費込み）が見合っているかを判定する指標です。すべて費用の合計で計算します。

### CPL {#cpl}

CPLは、リード1件の獲得にかかった費用（人件費込み）です。

```
CPL＝費用÷リード数
```

計算例（架空の会社の例・成長期）：1,280÷285＝4.5

CPLなら、受注が出る前の期の途中でも施策を比べられます。施策ごとの受注件数は少なく、ぶれやすいので、施策の判定はCPLで行います（[施策の判定](#judgment)）。

### CAC {#cac}

CACは、新規の受注1件の獲得にかかった費用（人件費込み）です。

```
CAC＝費用÷受注件数
```

計算例（架空の会社の例・成長期）：1,280÷12＝107

CACは受注1件のためにいくら使ったかを示す数字で、回収期間とCACの上限の判定のもとになります。人件費を入れるのは、外部費用だけだと、人手のかかる施策のCACが低く出るためです。

### ROI {#roi}

ROIは、1年間の受注の粗利から費用（人件費込み）を引いた額が、費用の何倍かを示す割合です。

```
ROI＝（受注金額×粗利率−費用）÷費用
```

- 期間は1年です
- マイナスになることもあります

計算例（架空の会社の例・成長期）：（3,000×40%−1,280）÷1,280＝−6%

売上ではなく粗利で見るのは、費用を取り返せたかどうかが粗利でしかわからないためです。期間を1年にするのは、予算も経営の評価も年度で決まるから。製造業では1社との取引が数年続くので、1年ではマイナスになることがあります。マイナスでも隠さず、回収期間と並べて示します。

### 回収期間 {#payback}

回収期間は、受注1件の獲得にかかった費用（CAC）を、その1社の粗利で取り返すまでの月数です。

```
回収期間（か月）＝CAC÷1社あたりの月の粗利
1社あたりの月の粗利＝平均単価×粗利率÷12
```

計算例（架空の会社の例・成長期）：107÷（100÷12）＝12.8か月

経営は「いつ取り返せるか」で投資を判断します。回収期間なら、1年のROIがマイナスでも、いつ取り返せるかを示せる。そのため、経営への説明の主役にしています（[経営への説明の順番](#explain)）。

### CACの上限 {#cac-limit}

CACの上限は、受注1件の獲得にかけてよい費用（人件費込み）の最大額で、1社あたりの年間粗利に取り返す年数をかけて出します。

```
CACの上限＝1社あたりの年間粗利×取り返す年数
```

計算例（架空の会社の例・成長期）：年間粗利100×取り返す年数1.5年＝150

取引年数（架空の会社では5年）をすべて見込むと、上限が甘くなります。何年で取り返すかは、経営と先に決めておく。そうすると、施策の判定がぶれません。

### 許容CPL {#allowable-cpl}

許容CPLは、CACの上限をリード1件あたりに直した額で、施策のCPLがこの額以下なら、受注の段階でもCACの上限に収まる見込みです。

```
許容CPL＝CACの上限×商談化率×受注率
```

計算例（架空の会社の例・成長期）：150×12÷285＝6.3（商談化率42÷285×受注率12÷42＝12÷285）

CACの上限をリード1件まで割り戻すと、施策をリードの段階で比べられます。受注が出る前の期の途中でも判定できるというわけです。率は今期の実績を使います。

### 施策の判定 {#judgment}

施策の判定は、施策のCPLを許容CPLと比べ、許容CPL以下なら「上限内」、超えたら「上限超え」とするものです。

```
施策のCPL≦許容CPL → 上限内
施策のCPL＞許容CPL → 上限超え
```

計算例（架空の会社の例・成長期）：展示会のCPL 2.8≦6.3で上限内、新しい業種向けLP＋広告（試行）のCPL 7.0＞6.3で上限超え

施策ごとの受注件数は少なく、1件の差でCACが大きく変わります。そのため、判定はCPLで行います。施策ごとに見ると上限内でも、共通の費用（MAツールなど）を含めてチャネルで集計し直すと、上限を超えることがある。施策とチャネルの両方で見ます。

## 経営への説明の順番 {#explain}

経営への説明の主役は回収期間です。1年のROIは並べて示します。

1. 回収期間：受注1件の費用を何か月で取り返すか
2. 1年のROI：回収期間と並べて示します。マイナスでも隠しません
3. CACの上限と許容CPLによる判定：上限超えの施策と、その扱い

計算例（架空の会社の例・成長期）：回収期間12.8か月、1年のROI −6%、全体のCAC 107はCACの上限150以内

## シナリオ {#scenario}

予算案は、率を変えた3つのシナリオで示します。

- 標準：今期の実績の率
- 悲観：商談化率と受注率を、それぞれ2割下げる
- 楽観：商談化率と受注率を、それぞれ2割上げる

率を変えるのは、費用より率のほうが見込みから外れやすいためです。2つの率を同じ幅で動かし、どこまで外れても上限内に収まるかを確かめます。

## 使わないもの {#not-used}

MKTG.AXでは、次のものを使いません。それぞれ理由を書きます。

- **予備費**：使い道の決まっていない枠は説明できず、削られやすくなります。期中に足りなくなったら、追加予算の稟議で扱います。
- **LTVから出す許容CPL**：数年先の取引を前提にするので、上限が甘くなります。年間粗利と取り返す年数から出すほうが、経営と合意しやすくなります。
- **限界CPL**：リード数が少ない部門では、1件増やすのにかかる費用を安定して測れません。
- **「粗利÷費用」のROI**：費用を引かないため、プラスでも赤字のことがあり、損益を読み違えやすくなります。
- **業界の広告宣伝費の比率との比較**：自社の売上目標や受注の目標とつながらず、予算の根拠になりません。
- **「LTV/CAC 3以上」という一律の基準**：一律の基準として使える根拠がありません。自社の年間粗利と取り返す年数から、CACの上限を出します。
